### 4. The six codes (memorize)

| Code | Means |
|---|---|
| `CONFIRMED_SOURCE_DEFECT` | The file's declaration is wrong. Both plants should refuse. Days 1–4 live here. |
| `CONFIRMED_LEGACY_DEFECT` | The main plant is wrong. **Friday.** Do not hunt it tonight. |
| `MODERN_DEFECT` | The new plant is wrong. Fix the plant, not the expected. |
| `APPROVED_BEHAVIOR_CHANGE` | Named, signed, rare. Not a vibe. |
| `CONTRACT_AMBIGUITY` | The YAML cannot decide. Escalate. Do not code a guess. |
| `UNRESOLVED` | Not shippable. Not servable. |

Zero tolerance unless the contract writes one. It does not.
